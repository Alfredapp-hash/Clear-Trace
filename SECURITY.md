# Security Policy

ClearTrace stores personal information about people requesting data-broker removals, so we
take reports seriously.

## Reporting a vulnerability

Report privately through GitHub: **Security → Report a vulnerability** on this repository
(private vulnerability reporting). Please do not open a public issue or pull request for a
security problem.

Include what you found, steps to reproduce, and the version or commit you tested. We will
acknowledge the report, keep you updated while we investigate, and credit you in the release
notes if you would like.

## Supported versions

| Version | Supported |
|---|---|
| Latest release on `main` | Yes |
| Older releases | No — upgrade first ([docs/self-hosting/upgrade.md](docs/self-hosting/upgrade.md)) |

## Scope and conduct

Test only against your own self-hosted instance. Do not access, change or keep data that is
not yours, and do not degrade a service other people rely on. Use test identities, never real
people's details.
